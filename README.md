# Movie Recommendation System

## About
This project recommends similar movies based on
their genres using Python.

## Features
- Displays available movies
- Accepts a movie name from the user
- Recommends up to 5 similar movies
- Simple and beginner-friendly Python code

## Technologies Used
- Python
- GitHub

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Run the command:

   python main.py
